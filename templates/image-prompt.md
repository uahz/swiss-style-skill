# AI 生图提示词模板

所有模板均已内置强制约束：12 栏网格、左对齐、三色平涂、双字重、禁装饰。
使用时只替换 `[ ]` 里的内容，不要删改约束条款——删掉任何一条都会破坏风格一致性。

---

## 1. 通用基础版

```
瑞士国际主义风格，[场景]，12 栏模块化网格系统，所有元素边缘严格对齐网格线
字体：新怪诞无衬线体（Helvetica / Neue Haas Grotesk / Inter），仅常规与粗体两种字重
排版：全部文字左对齐，右侧参差不齐，不对称构图，大面积留白，无居中无两端对齐
字号：超大号标题 + 极小号正文，强烈大小对比，无中间过渡字号
色彩：仅纯黑、米白底色、强调红 #DA291C，全部平涂
排除：无阴影、无渐变、无纹理、无噪点、无装饰插画、无 3D、无图标
元素：极细实线分隔区块，01 / 02 数字编号，小号年份与地点信息，[黑白摄影 / 红色几何矩形]
质感：理性、克制、精确、国际主义平面设计，高清版式稿
```

```
排除：阴影、渐变、纹理、装饰插画、3D、图标、emoji
构图：不对称，留白 ≥ 40%，视觉重心偏上偏左
```

## 6. 反向提示词（Negative Prompt）

生图工具支持负面提示时，直接追加：

```
渐变, 阴影, 投影, 发光, 纹理, 噪点, 浮雕, 玻璃拟态, 圆角卡片, 胶囊按钮,
装饰插画, 卡通, 3D 渲染, 具象图标, emoji, 纹样, 贴纸, 光斑, 居中排版,
两端对齐, 右对齐, 四级字号, 衬线体, 手写体, 多色配色, 高饱和
```

## 使用要点

1. **只换内容，不换约束**：替换 `[ ]`，保留所有风格条款。
2. **一次只给一个视觉锚点**：全画面红色元素最多两处（编号 + 一块几何/一条线）。
3. **文字内容别太长**：瑞士风格靠留白，正文超过 40 字就该拆栏或删。
4. **出图后对照 `SKILL.md` 校验清单逐条打勾**，不合格就重出，不要后期"修图补风格"。
