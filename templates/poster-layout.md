# 竖版海报版式规范

## 一、画布与网格

- 比例：`1 : 1.414`（A 系列）或 `3 : 4`（社交竖版）
- 外边距：上下左右完全相等，取短边的 6%–8%
- 栏数：**12 栏**，栏间距（gutter）= 1 个栏宽
- 基线网格：以正文行距为基准单位，所有文字基线对齐
- 所有元素（文字、细线、色块、照片边缘）必须落在栏线或基线

坐标表示（以排版区宽为 12U，gutter 为 1u）：

```
[1U][1u][1U][1u][1U][1u][1U][1u][1U][1u][1U][1u][1U][1u][1U][1u][1U][1u][1U][1u][1U][1u][1U]
 ↑栏1        ↑栏2        ↑栏3        ↑栏4        ↑栏5        ↑栏6        ↑栏7        ↑栏8 … 栏12
```

## 二、版式层级（从上到下，全部左对齐同一条起栏线）

### 1. 顶部信息区
- 位置：左上角，起第 1 栏
- 跨栏：2 栏
- 内容：`01` 编号 + 年份 + 地点
- 样式：编号用强调红 `#DA291C` Bold，年份地点用黑色 Regular
- 字号：极小（8–9pt 等效），字距 +2%

### 2. 主标题区
- 位置：中上，起第 1 栏
- 跨栏：6–8 栏
- 样式：黑色 Bold，字距 -3%，行距 0.95
- 字号：极大，单行高度约为排版区高度的 1/8
- 断行规则：按语义断行，断后仍与栏 1 左边缘对齐

### 3. 正文说明区
- 位置：中下，起第 1 栏（或起第 2 栏形成轻微错位）
- 跨栏：3–4 栏
- 样式：黑色 Regular，行距 1.45，左对齐不齐右
- 字号：极小（9–10pt 等效）
- 段间距：1 个基线单位

### 4. 视觉锚点区
- 位置：单侧（右侧或下侧），不对齐标题起栏线
- 尺寸：3–4 栏宽
- 形式：任选其一
  - 强调红 `#DA291C` 实心几何矩形
  - 高对比黑白摄影
- 约束：边缘必须压网格线，不得出血、不得圆角、不得投影

### 5. 底部信息区
- 细线：0.5–1pt 黑色实线，横贯第 1–12 栏
- 位置：距底边约为外边距的 1.5 倍
- 辅助信息：右下角，跨 2–3 栏，极小号 Regular（页码 / 出品方 / 网址）

## 三、留白与比例

- 空白（无任何元素）面积 ≥ **40%**
- 强调红总面积 ≤ **15%**
- 文字面积 ≤ **25%**
- 视觉重心：偏上 1/3、偏左 1/2 区域

---

## 四、三类常见构图

| 构图 | 结构 | 适用 |
| :--- | :--- | :--- |
| A 型（标题压顶） | 顶级标题 + 左下正文 + 右下红块 | 展览海报、讲座 |
| B 型（图左文右） | 左侧黑白照片 5–7 栏 + 右侧标题与正文 | 摄影展、品牌视觉 |
| C 型（极简单点） | 全留白 + 一个极大标题 + 一个红编号 | 宣言式、概念海报 |

## 五、交付检查

- [ ] 12 栏全部对齐，元素无越线
- [ ] 文字全部左对齐，右侧参差
- [ ] 只有 Regular / Bold 两种字重
- [ ] 只有黑 / 米白 / #DA291C
- [ ] 无渐变、无阴影、无纹理、无插画
- [ ] 留白 ≥ 40%，红色 ≤ 15%
- [ ] 编号、年份、地点齐全
