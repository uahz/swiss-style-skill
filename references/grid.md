# 网格系统规格

## 1. 基础计算

给定画布宽 `W`、高 `H`、外边距 `M = 0.06 * min(W,H) ~ 0.08 * min(W,H)`：

```
有效排版区宽 = W - 2M
栏宽 U = 有效排版区宽 / 23
gutter = U        # 栏间距等于 1 个栏宽
12 栏总宽 = 12U + 11U = 23U
```

**为什么除以 23**：12 栏 + 11 条 gutter，而 gutter = 1U，故总宽 = 23U。
这是让"栏宽 = 间距"成立的最小闭式解，也是 Müller-Brockmann 体系里最常用的比例关系。

第 n 栏左边缘 x 坐标：

```
x(n) = M + (n-1) * 2U      n = 1..12
```

第 n 栏右边缘：`x(n) + U`

## 2. 基线网格

- 基准单位 `b` = 正文行距（取正文号 × 1.45）
- 所有文字基线落在 `b` 的整数倍上
- 细线也吸附到基线，避免视觉抖动
- 标题块整体对齐基线网格，不单独浮动

## 3. 常见画幅的推荐参数

| 画幅 | 像素参考 | 外边距 M | 栏宽 U | 正文字号 |
| :--- | :--- | :--- | :--- | :--- |
| 3:4 竖版 | 1200 × 1600 | 76 | 45.5 | 20px |
| 1:1.414（A4 竖） | 1240 × 1754 | 78 | 47 | 20px |
| 16:9 横版 | 1920 × 1080 | 76 | 76 | 22px |
| 1:1 方图 | 1080 × 1080 | 72 | 40.7 | 18px |

数值为起始建议，实际按字体 x-height 与阅读距离微调。

## 4. 允许跨栏（这是唯一合法的"自由"）

| 元素 | 跨栏 | 说明 |
| :--- | :--- | :--- |
| 编号 / 元信息 | 2 | 固定在左上角起栏线 |
| 主标题 | 6–8 | 单行不超过 8 栏，超出就断行 |
| 正文段 | 3–4 | 超过 4 栏会破坏"小字"的视觉重量 |
| 视觉锚点 | 3–4 | 贴合网格边界，不居中 |
| 分隔细线 | 4–12 | 可贯穿部分或全部，不必满宽 |
| 数据块 | 3–4 | 3 个块 + 2 条线正好 12 栏 |

## 5. 对齐硬约束

- 所有元素的**左边缘**或**右边缘**必须等于某条 `x(n)` 或 `x(n)+U`
- 禁止"看起来差不多"的手动微调
- 文字块右端允许参差，但**块容器**的边界仍要对齐网格
- 图片出血只允许向画布外侧，不允许向内侵入排版区

## 6. 留白

- 空白（无任何元素）面积 ≥ 35%，竖版海报建议 ≥ 40%
- 留白优先集中在：右下、下方、标题与正文之间的呼吸区
- 禁止把留白平均分配到四边——那是对称，不是不对称

## 7. 快速验算

出稿后量三组数字：

1. 任意元素左边缘到版心左边 = 是否 `2U` 的整数倍
2. 相邻两元素间距 = 是否 `2U` 的整数倍（中间隔一栏）
3. 正文行距 = 是否等于基线单位 `b` 的整数倍

三项全过，网格就成立。
