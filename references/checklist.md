# 交付校验清单

打印出来放在桌上，每张稿子逐条打勾。任一项不过 → 重做，不做"后期修补"。

## A. 网格（6 项）

- [ ] 画面可数出 12 栏（栏宽 = 间距）
- [ ] 所有元素左边缘落在某条栏线 `x(n)`
- [ ] 相邻元素间距是 2U 的整数倍
- [ ] 文字基线对齐基线网格
- [ ] 照片/色块边缘贴合栏线，不出血进排版区
- [ ] 不对称：视觉重心明显偏上或偏左

## B. 字体（6 项）

- [ ] 全部为新怪诞无衬线体（Helvetica / Neue Haas Grotesk / Inter）
- [ ] 只出现 Regular 与 Bold 两种字重
- [ ] 无 Italic、无 Medium/Light/Black
- [ ] 字号只有两级（极大 / 极小），比值 ≥ 8
- [ ] 超大标题字距为负（-2% ~ -4%）
- [ ] 标题行距 ≤ 1.05，正文行距 1.35–1.5

## C. 对齐（4 项）

- [ ] 所有文字左对齐
- [ ] 右侧参差不齐（可见明显不齐的边缘）
- [ ] 无居中
- [ ] 无两端对齐（无字间距被拉伸的痕迹）

## D. 色彩（5 项）

- [ ] 只出现黑 `#000000`、米白 `#F2EFE8`、红 `#DA291C`
- [ ] 红色面积 ≤ 15%
- [ ] 红色只用于编号 / 细线 / 单块几何 / 单个强调词
- [ ] 无阴影、无渐变、无纹理、无噪点、无发光
- [ ] 第一视觉落点是标题，不是红块

## E. 元素（5 项）

- [ ] 图像只有黑白摄影或简单几何形
- [ ] 无装饰插画、卡通、3D、图标、纹样、贴纸、emoji
- [ ] 分隔线为 0.5–1pt 细实线
- [ ] 无圆角（所有矩形直角）
- [ ] 无胶囊按钮、无卡片容器

## F. 点缀（3 项）

- [ ] 有 `01` / `02` 类编号
- [ ] 有小号年份（4 位）
- [ ] 有小号地点或页码

## G. 构图（4 项）

- [ ] 留白 ≥ 35%（竖版海报 ≥ 40%）
- [ ] 只有一个视觉锚点（一块红 / 一张照片 / 一个极大数字）
- [ ] 无"填满"的冲动式排版
- [ ] 呼吸区集中在右下或下方，四边不均等

## H. 可读性（3 项）

- [ ] 缩略图尺寸下能认出主题
- [ ] 正文单行 ≤ 70 字符（拉丁）/ 30 字（中文）
- [ ] 红色未用于小字正文

---

## 快速三问（30 秒版）

1. **有没有第三、第四种颜色？** 有 → 失败
2. **有没有居中或加粗到四种字重？** 有 → 失败
3. **把画面缩小到 20% 看，还认得出是瑞士风格吗？** 认不出 → 失败

三问全过，再走 A–H 细项。
