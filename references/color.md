# 色彩系统

## 1. 三色唯一

| 名称 | 色值 | 职责 | 面积 |
| :--- | :--- | :--- | :--- |
| 黑 | `#000000` | 标题、正文、细线 | 10–25% |
| 米白 | `#F2EFE8` | 底色 | 55–75% |
| 强调红 | `#DA291C` | 编号、关键线、单块几何 | ≤ 15% |

> 红色取 `#DA291C` 而非更亮的正红，是因为它在米白底上对比足够但不过度抢眼，接近 1950–60 年代瑞士印刷的油墨红。

## 2. 为什么不能加第四色

瑞士风格的视觉冲击来自**字号对比 + 网格秩序 + 大面积留白**，不是配色。
一旦引入第四色，视觉焦点会被颜色分散，字号对比的力度被削平，风格立即滑向"商业简约风"。

若客户强制要求品牌色，处理方式：
1. 把品牌色作为**第五色**仅用于小面积（Logo、标注），红色降为纯几何
2. 或整体转为**纯黑 + 米白两色版**，把品牌色完全剥离
3. 明确告知：加色即退出瑞士风格范畴，不要一边说"要瑞士风"一边塞四个色

## 3. 红色使用规则

允许：
- `01` `02` 编号本身
- 一条细线（分隔或强调）
- 一块纯色几何（矩形/圆），直角无圆角
- 单个强调词（最多一处）

禁止：
- 红色标题大面积铺满
- 红色渐变、红色阴影、红色描边发光
- 红色做背景整版
- 同一画面出现两块以上竞争性红块

**判定标准**：闭眼再看一眼，视线第一落点应该是标题，不是红色。如果先看到红，红色超量了。

## 4. 灰度使用

- 允许黑色通过**透明度**产生 1–2 级灰（仅用于次级信息，如页码）
- 禁止使用独立的灰色色值（如 `#888888`）——那是第四种颜色
- 照片可用黑白灰阶（属图像，不属配色系统）

## 5. 平涂硬约束

必须全平涂。以下一律禁止：

```
box-shadow, drop-shadow, text-shadow
linear-gradient, radial-gradient
noise, grain, film texture
bevel, emboss, inner shadow
glow, blur, backdrop-filter
opacity 叠加产生的半透明层（除上述灰度例外）
```

**唯一允许的"效果"是纯色块与细线本身。**

## 6. 对比度与可读性

| 组合 | 对比度 | 可用性 |
| :--- | :--- | :--- |
| 黑 on 米白 | ≈ 19:1 | 主用 |
| 红 `#DA291C` on 米白 | ≈ 4.8:1 | 仅限 ≥ 14pt 粗体或 ≥ 18pt 常规，不用于长正文 |
| 白 on 黑 | ≈ 21:1 | 允许（反白版式） |
| 红 on 黑 | ≈ 3.4:1 | 不推荐，仅装饰性细线可用 |

红色**不能用于小字正文**，这是无障碍底线，不是审美选择。

## 7. 黑白版（无红色的变体）

当场景不允许彩色（报纸、激光打印、严肃学术）：
- 去掉红，编号改为黑色 + 加粗
- 强调改为：加大留白、加粗细线、或反白块
- 仍然成立，因为瑞士风格的骨架是网格与字号，不是颜色

## 8. 屏幕适配

- 米白底在 OLED 上偏黄，必要时可提亮至 `#F5F2EC`，但不得改为纯白
- 纯白底会显得"廉价文档风"，破坏纸张质感联想
- 印刷转屏幕时，黑色保持纯黑，不做四色黑替代
