# 字体与排版规格

## 1. 允许的字体

| 优先 | 字体 | 说明 |
| :--- | :--- | :--- |
| 1 | Helvetica Now / Neue Haas Grotesk | 原版数字复刻，字形最正 |
| 2 | Helvetica Neue | 系统普遍可用 |
| 3 | Inter | 免费开源，数字屏幕显示优化 |
| 备 | Arial | 仅在无以上字体时的兜底，不推荐主视觉 |

**禁止**：衬线体（Times / Georgia / 宋体）、手写体、圆体、装饰体、等宽体（正文）、可变字重滥用。

## 2. 只用两种字重

```
Regular (400)  正文、标签、元信息、编号后缀
Bold (700)     标题、关键数字、强调词
```

**禁用**：Light(300)、Medium(500)、Semibold(600)、Black(900)、Thin、Italic。
需要强调时**不加字重**，改用：放大、换色（仅红）、独立成行、加留白。

> 只有两个字重的意义在于：任何信息层级都靠**尺寸和位置**建立，而不是靠字重堆叠。这是瑞士风格与其他风格最大的分野。

## 3. 字号阶梯（严格两级）

| 层级 | 相对正文倍数 | 用途 |
| :--- | :--- | :--- |
| 极大 | 8–20× | 主标题、关键数字 |
| 极小 | 1× | 正文、标签、元信息、页脚 |

不存在 1.5×、2×、3× 这种"小标题"。需要区分信息时，用**栏宽、留白、颜色、位置**区分。

## 4. 字距（tracking）

| 场景 | 值 | 原因 |
| :--- | :--- | :--- |
| 超大标题 | -2% ~ -4% | 大字距孔洞过大，必须收紧 |
| 常规标题 | -1% ~ -2% | |
| 正文 | 0 ~ +2% | |
| 全大写小字 | +3% ~ +8% | 补偿大写缺少升部，避免糊成一团 |
| 数字编号 | +2% | 便于识别 |

## 5. 行距（leading）

| 层级 | 倍数 | 说明 |
| :--- | :--- | :--- |
| 极大标题 | 0.95–1.05 | 小于 1 才能形成"块"的实心感 |
| 极小正文 | 1.35–1.5 | 低于 1.3 会闷，高于 1.6 会散 |
| 标签 / 元信息 | 1.2–1.3 | 单行或双行，紧凑 |

## 6. 断行规则

- 按**语义**断行，不在词中间断
- 断行后每行左边缘对齐同一条栏线
- 标题最多 2 行；超过 2 行的标题应缩短文案，不是缩小字号
- 竖排英文标题优先在名词短语边界断（如 `SWISS` / `STYLE`）
- 禁止孤行（最后一行只剩 1 个词）

## 7. 大小写

| 场景 | 规则 |
| :--- | :--- |
| 主标题 | 全大写最常见，也可句首大写 |
| 正文 | 正常句首大写 |
| 编号 / 元信息 | 全大写 + 增字距 |
| 地点 | 全大写，可保留变音符（ZÜRICH） |

全大写会增加视觉重量，只能在极小字号或标签上使用，不要用在中长正文。

## 8. 数字

- 用等宽数字（tabular figures）保证数据列对齐
- 数据页的关键数字：Bold + 极大 + 字距 -3%
- 单位与数字之间用半个空格，不紧贴
- 年份用 4 位，不用 `'57` 这种缩写（除非是刻意的年代标记）

## 9. 排版呼吸

- 标题与正文之间的垂直间距 ≥ 2 个基线单位
- 标题块与上方的编号行之间 ≥ 3 个基线单位
- 页脚细线上方 ≥ 2 个基线单位
- 文字块最大宽度：正文单行 ≤ 70 字符（拉丁）/ ≤ 30 字（中文）

## 10. 中英混排注意

- 中文使用思源黑体 / 苹方 / Noto Sans SC，字重仍只用 Regular 与 Bold
- 中英混排时，英文用 Helvetica 系，中文用黑体，两者字面高度需对齐
- 中文字距统一 +1% ~ +2%，比拉丁略宽才不显拥挤
- 中文标题不做负字距，否则笔画粘连
